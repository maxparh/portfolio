# Портфолио Максима

Личный сайт-портфолио DevOps, SRE и Full-stack разработчика: проекты, навыки, блог и контакты.

На сайте можно посмотреть выполненные работы, узнать о моём опыте и отправить сообщение или запрос на обновления. На главной странице есть интерактивный терминал для знакомства с портфолио.

Сайт разработан на Vue 3 и TypeScript с использованием Vite и Tailwind CSS. Для размещения используется Cloudflare Pages, для обработки форм — Pages Functions.
